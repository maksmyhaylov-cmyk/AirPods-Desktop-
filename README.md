# AirPodsWin

Windows-додаток (один `.exe`, без встановлення) для нормальної роботи AirPods з Windows 10/11.

## Що він вирішує

Головна причина «поганого звуку» AirPods на Windows — профіль **Hands-Free (HFP)**.
Щойно будь-яка програма (Discord, Teams, Zoom, браузер, гра) відкриває мікрофон,
Windows перемикає навушники з якісного стерео (A2DP) на моно-«телефонну» якість.

AirPodsWin:

- **Заряд** лівого, правого навушника і кейса, індикатор зарядки — у вікні та в треї
  (як спливаюче вікно на iPhone). Цифра в треї — найнижчий заряд у десятках (`8` = 80%).
- **Датчик вуха** — пауза музики/відео, коли виймаєте навушник, і продовження, коли вставляєте назад
  (Spotify, YouTube у браузері, медіаплеєри — усе, що керується медіаклавішами Windows).
- **Завжди стерео** — автоматично робить пристроєм за замовчуванням стерео-вихід «Headphones (AirPods)»,
  а не «Headset … Hands-Free».
- **Не використовувати мікрофон AirPods** — мікрофоном за замовчуванням лишається вбудований
  у ноутбук / вебкамеру, тож звук у навушниках не падає до моно під час дзвінків.
- **Вимкнути / увімкнути Hands-Free** однією кнопкою (найнадійніший спосіб: Windows фізично не зможе
  перемкнути AirPods у погану якість; мікрофон AirPods при цьому не працює). Потрібні права адміністратора.
- **Перепідключити** — швидко перезапускає аудіо-з'єднання, коли звук зник або заїкається.
- Сповіщення про низький заряд, автозапуск з Windows, робота у треї.

## Як отримати exe

**Готовий файл:** вкладка *Actions* → workflow **Build AirPodsWin** → останній запуск → артефакт `AirPodsWin`.
Для релізу створіть тег `v1.0.0` — exe з'явиться на сторінці *Releases*.

**Зібрати самому** (потрібен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)):

```powershell
dotnet publish src/AirPodsWin.csproj -c Release -o publish
# результат: publish\AirPodsWin.exe (self-contained, .NET встановлювати не треба)
```

## Використання

1. Спарте AirPods з Windows як звичайно (Параметри → Bluetooth → Додати пристрій,
   на кейсі затисніть кнопку до білого блимання).
2. Запустіть `AirPodsWin.exe`. Відкрийте кейс поруч із комп'ютером — з'явиться заряд.
3. Закриття вікна ховає програму в трей (біля годинника); вихід — правий клік по іконці → «Вихід».

Налаштування зберігаються у `%AppData%\AirPodsWin\settings.json`
(там можна змінити `DeviceNameFilter`, якщо навушники перейменовані без слова «AirPods»,
і `MinRssi`, якщо поруч багато чужих AirPods).

## Як це працює

- Заряд і датчик вуха: AirPods постійно транслюють Bluetooth LE-пакет Apple «Proximity Pairing»
  (manufacturer `0x004C`, тип `0x07`); програма слухає його через WinRT `BluetoothLEAdvertisementWatcher`
  і вибирає найсильніший сигнал (ваші навушники поруч, чужі — далі).
- Аудіо: Core Audio (`IMMDeviceEnumerator`, `IPolicyConfig`) для вибору пристроїв за замовчуванням.
- Профілі: `BluetoothSetServiceState` з `bthprops.cpl` (Hands-Free `0x111E`, Headset `0x1108`, A2DP `0x110B`).
- Пауза/відтворення: `GlobalSystemMediaTransportControlsSessionManager`.

Вимоги: Windows 10 2004+ або Windows 11, Bluetooth 4.0+ (LE).
